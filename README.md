📚 BookBuddy – Book Trading Platform

About the Project

BookBuddy is a web-based platform that allows users to list, discover, and trade books with other users. It encourages book reuse and makes it easier for readers to find books they want.

Features

* User registration and login
* Browse available books
* Add and manage book listings
* Book trading functionality
* MySQL database integration
* Frontend and backend separation

Technologies Used

* Frontend: HTML, CSS, JavaScript, Bootstrap
* Backend: PHP
* Database: MySQL
* Local Server: XAMPP

Project Structure

* admin/ – Administration-related files
* backend/ – Backend logic and database operations
* frontend/ – User interface and frontend pages

Installation

1. Install XAMPP.
2. Download or clone this repository.
3. Place the project folder inside XAMPP’s htdocs directory.
4. Start Apache and MySQL.
5. Create the required database in phpMyAdmin.
6. Configure the database connection.
7. Open http://localhost/BookBuddy/ in your browser.
